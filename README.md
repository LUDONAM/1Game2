# Буква за буквой

60 самостоятельных уровней: 20 на движения пальцев, 20 цельных текстов, 20 заданий с пунктуацией. После прохождения: разбор результата, сравнение с прошлой попыткой того же задания и короткая тренировка ошибок. На карточках показаны лучшая точность и рекорд скорости.

Enter на экране результата открывает следующий уровень. После уровня 60 — список уровней. Если выбрана другая кнопка клавишей Tab, Enter нажимает её. Во время печати Enter не пропускает задание.

История прежних версий сохраняется; начатые задания продолжаются с прежним текстом. Новые рекорды считаются отдельно. Работа над ошибками не засчитывается как прохождение уровня курса.

Аккаунты отключены. Прогресс хранится в браузере. Для публикации загрузите index.html, style.css, app.js, config.js и lessons.js в корень GitHub Pages.

## Единая версия

index.html открывает игровую главную с персонажем, клавиатурой и объектами. В этой же версии доступны все 60 уровней, рекорды, разбор ошибок, Enter и кнопки скачивания/загрузки прогресса в разделе «Мои результаты». game-variant.html перенаправляет на главную для совместимости со старой ссылкой.

Загрузите все файлы из архива site-complete.zip в корень репозитория с заменой. Распакуйте ZIP перед загрузкой.
